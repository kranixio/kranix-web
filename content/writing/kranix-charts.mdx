# kranix-charts

> Helm charts — install the full Kranix platform on Kubernetes in one command.

`kranix-charts` packages **kranix-core**, **kranix-api**, **kranix-operator**, optional **kranix-mcp**, CRDs, and RBAC into configurable Helm releases. Recommended for any environment beyond local Docker dev.

## What gets installed

```
Helm  →  kranix (umbrella)
           ├── kranix-core
           ├── kranix-api (+ Service)
           ├── kranix-operator
           ├── kranix-mcp [optional]
           ├── CRDs
           └── RBAC / NetworkPolicies / PDBs
```

## Prerequisites

- Kubernetes 1.27+
- Helm 3.12+
- `kubectl` configured for your cluster

## Install full platform

```bash
helm repo add kranix https://charts.kranix.io
helm repo update

helm install kranix kranix/kranix \
  --namespace kranix-system \
  --create-namespace

kubectl get pods -n kranix-system
```

## Install individual components

```bash
helm install kranix-core kranix/kranix-core -n kranix-system --create-namespace
helm install kranix-api kranix/kranix-api -n kranix-system --create-namespace
helm install kranix-operator kranix/kranix-operator -n kranix-system --create-namespace
```

## Features

- Umbrella or standalone charts
- Environment overlays (dev / staging / production)
- Optional MCP, ingress, OpenTelemetry
- HA profile with PDBs and anti-affinity
- Pre-upgrade validation hooks
- ArgoCD app-of-apps template

Connect the CLI after install:

```bash
kranix login --server http://kranix-api.kranix-system.svc:8080
```
